This map shows the ACLED conflict data for Haiti between October 2022 and March 2024. There are three elements:
  • Conflict incidents are represented by color-coded 'pops'; yellow for an armed clash, red for an attack and green for looting.
  • Each 'pop' leaves a blue 'stain'; these are additively transparent, so the more conflict incidents occur in an area the more opaque the stain becomes.
  • Departments also shade towards red as more incidents occur
Presented with apologies to the colourblind; this is a prototype, but can be recreated in more accessable colours. There are also some known issues - departments will lose their shading if there is no further data in the timeline for them, and there is no data for the latter half of March 2024.
